PERUBAHAN PASSWORD TEKS BIASA

1. Registrasi menyimpan password seperti yang diketik pengguna.
2. Login membandingkan password biasa dari database.
3. Admin dapat melihat dan mengubah password pada menu User Credentials.
4. Jika lupa password, buka lupa_password.php dari link pada halaman login.
5. Untuk database yang sebelumnya sudah berisi hash, import DB/reset_password_plaintext.sql.
6. Akun hash yang tidak termasuk akun bawaan harus direset melalui admin atau halaman Lupa Kata Sandi karena hash tidak dapat diubah kembali menjadi password lama.
